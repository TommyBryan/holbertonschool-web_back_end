# ES6 classes

## Setup

1. Install NodeJS 20.x.x
(in your home directory):

```bash
curl -sL https://deb.nodesource.com/setup_20.x -o nodesource_setup.sh
sudo bash nodesource_setup.sh
sudo apt install nodejs -y
```

```bash
$ nodejs -v
v20.15.1
$ npm -v
10.7.0
```

2. Install Jest, Babel, and ESLint
**Install Jest using:**
